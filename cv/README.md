# Online CV

This is my professional CV/Resume, built with HTML/CSS and optimized for both web viewing and PDF printing.

## [View Online](https://ebuitragod.github.io/ebuitragod/)

## Features
- Responsive design (mobile-friendly)
- Print-optimized styles
- Clean, professional layout
- Fast loading
- SEO-friendly

## Technologies Used
- HTML5
- CSS3 (with CSS Grid and Flexbox)
- Vanilla JavaScript
- Font Awesome Icons

## How to Print as PDF
1. Click the "Save/Print as PDF" button
2. Or use Ctrl+P (Cmd+P on Mac)
3. Select "Save as PDF" as destination
4. Use Chrome or Edge for best results
